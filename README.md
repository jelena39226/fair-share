# FairShare

FairShare is a responsive student project management application.

## Features

- User registration and login
- Project creation
- Team management
- Kanban board with drag and drop
- Product backlog
- Sprint planning
- Task assignment and prioritization
- Progress dashboard
- Sprint retrospective

## Stack

- Next.js and React
- TypeScript
- Tailwind CSS
- Prisma
- PostgreSQL
- NextAuth
- dnd-kit
- Recharts
